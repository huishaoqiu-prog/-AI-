# 头七 / TOUQI v1.0

[电脑浏览器直接游玩](https://huishaoqiu-prog.github.io/-AI-/touqi/) · [下载 Windows 离线版](https://huishaoqiu-prog.github.io/-AI-/touqi/download-windows.html) · [Godot 4.7 源码](./TouQi-v1.0-source.zip)

头七夜，独自守灵。长明灯不能灭，规矩不能破——可这些规矩，真的都是奶奶写的吗？

二〇〇三年腊月，林默回到槐荫村，为奶奶守头七。三叔留下一张奶奶亲笔写的规矩，锁上大门离开了。奶奶是村里最后一个扎纸匠：灵堂里摆着她的棺材，扎纸铺里站满了没画眼睛的纸人，西厢门上贴着一道封了二十年的黄符。院子里，有什么东西正踩着纸片沙沙作响。它看不见你，但它听得见。

中式民俗恐怖解谜：规则怪谈推理、听声潜行、六个时辰章节、三个结局，初次游玩约 25–40 分钟。美术、音效、音乐全部由代码生成。

## 操作

- 电脑键盘：WASD 移动，Shift 跑（很吵），Ctrl 潜行（几乎无声），E 调查/确认，Q 给油灯添油，R 查看规矩，Tab 笔记，Esc 暂停，F11 全屏。
- 需要键盘，暂不支持手机触屏。建议戴耳机。

Windows 下载页会自动合并并校验分段文件，保存为标准 ZIP。解压后运行 `头七.exe`，压缩包里附有攻略。浏览器版需要支持 WebGL 2 的浏览器。

源码用 Godot 4.7 打开 `project.godot` 即可运行，策划和攻略都在源码包里。

Godot 引擎许可见 [GODOT-LICENSE.txt](./GODOT-LICENSE.txt)，字体（Fusion Pixel Font）许可见 [FONT-LICENSE.txt](./FONT-LICENSE.txt)。
