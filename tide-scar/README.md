白天修复盐场山顶电台，月夜在南堤引导救援船。潮汐会改变路线；搬运电池、取暖和使用浮板都由玩家选择。没有通关时限。

## 操作

- 电脑：WASD 移动，Shift 疾行，E 互动或长按发信号，Q 放下电池，Tab 显示地点标记，Esc 暂停。月夜引航时用左右方向键转灯，再按 E 确认。
- 手机：横屏游玩，左侧摇杆移动；右侧按钮用于互动、疾行、放下电池、地点标记与暂停。长按互动按钮发信号。月夜引航时用摇杆左右转灯，再点确认。
- 标题画面可选常规巡检或快潮巡检。电脑按 F8 可观看路线演示。

Windows 下载页会自动合并并校验分段文件，保存为标准 ZIP。解压后运行 `TideScar-v0.5.4.exe`。浏览器版需要支持 WebGL 2 的浏览器。
